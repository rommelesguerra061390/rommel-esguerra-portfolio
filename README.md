# Rommel's Digital Showcase

Create a polished personal portfolio website for Rommel Esguerra, a GoHighLevel Specialist and AI & Automation Specialist. Use his name as the text logo. Include sections for profile/hero, services, work experience, previous works/sample projects, testimonials, education and skills/tools, and contact. Enter the resume content supplied in chat, including contact links and professional summary. Make it modern, credible, responsive, conversion-focused, and use appropriate placeholder testimonials clearly presented as sample client feedback if no real testimonials were supplied.
